make-core

version

WordPress

Make the current WordPress site ready to be a core site.

Installation

Source: https://moria.whyayh.com/rel/released/software/own/WP-make-core/

  1. Download the make-core-0.5.1.zip file.
  2. Use Add Plugins, Upload Plugin, Install, Activate

How do I use this plugin?

Prepare

  1. Install this plugin to your main WP site.

  2. Add "core" pages and posts that will replace existing pages. For example:

    • Duplicate your front page to "Core Home" page, then delete all links and reference that are specific to your site. Add links to other "core" example pages and posts.
    • Example core posts can be created, but their status should be "private."

Identify the pages and posts that should remain

  1. Go to Settings -> MakeCore. With blank Keep text boxes, click on the "List" button (only).

  2. Copy the URIs listed in the Delete Posts and Delete Pages text boxes, to a text editor. Delete the URIs that should be deleted.

  3. Copy the URIs from the editor to the Keep text boxes. Click on the "List" button (only).

  4. Repeat steps 2 and 3 until the Delete lists look OK. DO NOT CLICK ON THE "Delete" button.

Create the core pages and posts

  1. Using your hosting provider's process, copy your main site to a "test" site. ALL THE OTHER STEPS ARE DONE ON THE TEST SITE COPY.

  2. Sign in to the test site.

  3. Go to Settings -> MakeCore. Click on the the "List" button.

  4. Adjust the Keep text boxes as needed.

  5. Repeat step 3 and 4, until Delete list is OK.

  6. Click on the "Delete" button:

    • You will be prompted, with: Are you sure?
    • The URIs in the List boxes will be deleted
    • Revisions will be removed from remaining pages and posts
    • Media files that are not referenced will be deleted

Manual Cleanup Steps

  • If Imagely plugin is installed:

    • Delete all Galleries
    • Delete all Albums
    • Delete all Tags

  • Replace front page with "Core Home"

    • Duplicate "Core Home" and edit it.
    • Change title to "Home"
    • Change slug to "Home"
    • Save
    • Settings -> Reading, Set Homepage to "Home"

  • Make "private" example core posts "public."

  • Appearance -> Customize

    • Remove Logo
    • Change Site Identity to "Core Sample"

  • Edit change-log

    • Remove all of the entries.
    • Add Date for when this core was created.

  • Remove API keys and other personal stuff

    • Remove Claude API
    • Remove personal IPs from Wordfront and AES
    • Remove Wordfront free license
    • Remove USP Pro plugin lifetime license (URL? TBD)
    • Remove FastBots plugin

  • Remove all users

    • Create gmail CivCoreAdmin@gmail.com (save the password)
    • Create WP admin account CivCoreAdmin@gmail.com (save the password)
    • Remove all user except leave CivCoreAdmin@gmail.com
    • When the import files are given to others, give them the gmail account and the WordPress user names and passwords.
    • After the WP site is imported, an admin account should be setup immediately and the WP CivCoreAdmin@gmail.com account must be deleted.

Export the Core (Hostinger)

  • Make a backup of the "test" site (or wait until a backup is made).
  • Log in to your Hostinger hPanel.
  • Go to Websites and click Manage next to your WordPress site.
  • On the left sidebar, navigate to Files -> Backups.Under Files backups, click Select.
  • Choose the most recent date from the dropdown menu and click Next step.
  • Click on Website backup. This includes all files and DB.
  • Download and rename the backups and copy them to Google Drive.
    • Civ-core-files-VER.tar.gz
    • Civ-core-db-VER.sql.gz
